      동시 요청과 TCP 연결 재사용

      요청을 한꺼번에 보내고, 요청마다 새 TCP 연결을 맺었는지, 기존 연결을 재사용했는지를 시간 순서로 그립니다.

      버튼을 눌러 보세요
      브라우저에서 빈 연결 기다림 새 TCP 연결 (3-way handshake) 서버 처리 기다림 응답 받기

      브라우저는 서버 하나에 연결을 6개 정도만 엽니다. 새 연결(주황)은 처음 몇 개뿐이고, 나머지 요청은 빈 연결이 생길 때까지 기다렸다가(회색) keep-alive로 같은 연결을 재사용합니다.

      서버 로그를 옆 터미널에 띄워 두면, 버튼을 누를 때마다 요청이 찍히는 것을 같이 볼 수 있습니다.
